BUILDCREW LABOR MANAGEMENT SYSTEM

RUN
1. Extract the ZIP folder.
2. Open index.html in a modern browser (Chrome/Edge/Firefox).
3. Sign in: Username admin; Password BuildCrew2026!

FEATURES
- 15 fictional worker records
- 75 attendance records for five sample working days
- 75 daily assignment records
- 10 work activity master records
- Accomplishment records for five days and 10 activities
- Dashboard: workforce, attendance, hours, cost, trade breakdown, productivity watchlist
- Add/edit/delete/search records; CSV exports; JSON backup; reset demo data

IMPORTANT
This is a browser-only academic prototype. Data is stored in localStorage on the current browser/device, not a shared server database. Demo login is not production-grade security. All personnel and payroll data is fictional. For public instructor access, deploy the folder to a static hosting provider; localStorage data will not sync between different users.
